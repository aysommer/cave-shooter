# Cave Shooter

Пиксельный 2D-шутер с видом сверху для двух игроков по сети, работает в браузере. План разработки: [docs/PLAN.md](docs/PLAN.md).

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:5173. Свой seed можно передать в адресе: `?seed=42`.

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Движение |
| Мышь | Прицел |
| ЛКМ | Огонь (пистолет и дробовик — по клику, автомат — зажать) |
| Q | Сменить оружие |
| F1 | Отладка: FPS, тик, сущности, хеш мира, хитбоксы |
| R | Новый мир с другим seed |

## Проверки

```bash
npm test
```

Прогоняет минуту игры в Node: одинаковые seed и ввод дают одинаковый мир, клон на середине доигрывается в тот же мир, игроки и пули никогда не оказываются внутри стен.

## Устройство

- `src/sim/` — чистая симуляция: без DOM, звука, сети, `Math.random()` и `Date.now()`. Мир меняется только через `step(world, inputs)`.
- `src/core/` — цикл с фиксированным шагом 60 Гц, ввод, рендер с целочисленным масштабированием, seed-RNG, пиксельный шрифт.
- `src/sim/level/` — тайловая карта и столкновения со стенами; `src/sim/entities/` — игрок и пули.
- `src/data/` — описания оружия (чистые данные).
- `src/view/` — отрисовка мира (только чтение состояния), камера, эффекты, черновые спрайты, отладочный оверлей.
