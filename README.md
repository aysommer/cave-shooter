# Cave Shooter

Пиксельный 2D-шутер с видом сверху для двух игроков по сети, работает в браузере. План разработки: [docs/PLAN.md](docs/PLAN.md).

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:5173. Вместе с игрой стартует сервер соединения (signaling) на порту 9000.

- **Создать игру** — получите код комнаты и ссылку-приглашение.
- **Войти** — введите код комнаты напарника (или откройте его ссылку `?join=КОД`).
- **Играть одному** — без сети.

Проверить на одном компьютере: откройте игру в двух окнах (лучше в разных профилях или в обычном и приватном окне), в одном создайте комнату, во втором войдите по коду.

### Игра по локальной сети

```bash
npm run dev -- --host
```

Напарник открывает `http://<IP вашего компьютера>:5173`. Для игры через интернет нужен сервер с TURN (этап 10, Docker на VPS).

### Docker (сервер соединения + TURN)

```bash
docker compose -f docker-compose.dev.yml up -d
```

```bash
npm run dev
```

`npm run dev` увидит, что порт 9000 занят контейнером, и будет работать через него. Настройки — в `.env` (образец: `deploy/.env.example`). Проверить, что всё идёт через TURN: добавьте к адресу `?relay=1` у обоих игроков.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Движение |
| Мышь | Прицел |
| ЛКМ | Огонь (пистолет и дробовик — по клику, автомат — зажать) |
| Q | Сменить оружие |
| F1 | Отладка: FPS, тик, сущности, хеш мира, сеть (RTT, трафик, исправления), графики |
| F2 | Имитация плохой сети: 50 мс → 150 мс и 5% потерь → 250 мс и 10% потерь → выкл |
| R | Новый мир (только в одиночной игре) |
| N | Отладка: следующий уровень (одиночная игра и хост, гость переходит следом) |
| M | Звук вкл/выкл |
| F3 | Тряска экрана вкл/выкл |

Настройки звука и тряски запоминаются в этом браузере.

Портал открывается, когда убиты все враги; уровень пройден, когда все живые игроки встают в него (стрелка у края экрана показывает, где он). Каждые три уровня меняется биом: пещеры, кристальные гроты, магмовые недра.

Враги: **Кусач** (бегает и кусает, делает рывок), **Плевун** (держит дистанцию и плюётся), **Броненос** (медленный, крепкий, стреляет веером), **Пузырь** (подбегает и взрывается, ломает стены), **Гнездо** (стоит на месте, выводит Кусачей и стреляет кольцом). Перед выстрелом враги мигают белым.

У героя 8 HP; после попадания он ненадолго неуязвим (мигает). Упавший напарник возвращается на следующем уровне с половиной здоровья. Если упали все, через 3 секунды начинается новый забег.

```bash
npm test
```

- `scripts/sim-determinism.mjs` — минута игры в Node: одинаковые seed и ввод дают одинаковый мир, клон на середине доигрывается в тот же мир, игроки и пули никогда не оказываются внутри стен.
- `scripts/level-test.mjs` — 720 сгенерированных уровней (60 seed × 12 глубин): пещера связна, всё стоит на полу, края из камня, генерация детерминирована, все карты разные, выход далеко от старта; разрушение стен и повтор изменений.
- `scripts/combat-test.mjs` — стрельба убивает врагов, Кусачи догоняют и убивают стоящего игрока, после гибели всех начинается новый забег, неуязвимость после удара, взрыв Пузыря, портал закрыт пока живы враги, упавший напарник возвращается; стоимость ИИ (28 врагов — около 0,1 мс на тик).
- `scripts/audio-test.mjs` — все звуковые эффекты синтезируются без ошибок и перегруза, у каждого оружия есть звук.
- `scripts/netcode-test.mjs` — протокол (кодирование и декодирование пакетов) и сетевая игра хоста и гостя через имитацию сети с задержкой, джиттером и потерями: герой гостя после предсказания сходится с героем у хоста; гость переходит на следующий уровень вслед за хостом и получает разрушенные стены, карты совпадают.

## Устройство

- `src/sim/` — чистая симуляция: без DOM, звука, сети, `Math.random()` и `Date.now()`. Мир меняется только через `step(world, inputs)`.
  - `entities/enemy.js` — поведение врагов; `ai/nav.js` — линия видимости и поле путей к игрокам; `combat.js` — урон, смерть, взрывы.
  - `level/` — генерация пещер (`generate.js`), жизнь уровня: портал, разрушаемые стены (`level.js`), тайловая карта и столкновения (`tilemap.js`); `entities/` — игрок и пули.
- `src/data/` — описания оружия, врагов и биомов (чистые данные).
- `src/core/` — цикл с фиксированным шагом 60 Гц (в фоновой вкладке тикает через Web Worker), ввод, рендер, seed-RNG, пиксельный шрифт.
- `src/view/` — отрисовка мира (только чтение состояния): карта с автотайлингом и декором биома (`map-renderer.js`), камера, портал, черновые спрайты, отладочный оверлей.
  - `event-fx.js` превращает события симуляции в эффекты и звуки; `particles.js` — частицы (гильзы и капли падают на пол); `decals.js` — трупы, кровь, гильзы и копоть на полу до конца уровня; `feedback.js` — тряска, отдача камеры, замирание кадра (хитстоп).
- `src/audio/` — свой маленький синтезатор в духе sfxr (`synth.js`), описания звуков (`sounds.js`) и проигрыватель с громкостью и панорамой по расстоянию (`audio.js`).
- `src/net/` — сеть: PeerJS, протокол, хост, гость, имитатор плохой сети.
- `src/game/` — режимы: `local-game.js` (одиночная игра и хост), `guest-game.js` (гость: предсказание своего героя, сверка с хостом, интерполяция остального).
- `src/ui/` — лобби и панель комнаты.
- `server/signal/` — сервер соединения (PeerJS) и выдача временных логинов TURN, с Dockerfile.

### Как работает сеть

Хост — единственный, у кого идёт настоящая симуляция. Гость каждый тик отправляет ввод (с повтором последних 6 кадров на случай потерь) по ненадёжному каналу WebRTC. Хост применяет по одному вводу гостя за тик и 30 раз в секунду шлёт снимок мира (бинарный, ~100–200 байт) с номером последнего применённого ввода. Гость сразу применяет свой ввод к своему герою и своим пулям, а при получении снимка берёт состояние героя от хоста и заново применяет ещё не подтверждённые нажатия. Остальные объекты гость рисует на 100 мс в прошлом, плавно интерполируя между снимками.

Уровни по сети не передаются: и хост, и гость генерируют пещеру сами из общего seed и номера уровня. Снимок несёт номер уровня, а хост отдельно сообщает хеш карты, и гость сверяет его со своим (в F1 видно `OK`). Разрушенные стены идут по надёжному каналу.

Враги живут только у хоста. Гость получает тех, кто в пределах полутора экранов от его героя (так снимок с полным уровнем врагов укладывается примерно в 400 байт), и рисует их с интерполяцией. Свои пули гость останавливает о врагов на своём экране сразу, но попал ли он на самом деле, решает хост.
